# My AI Coder

AI coding assistant for Visual Studio Code.

## Features

- Ask AI questions
- Explain code
- Analyze programming problems
- Get coding assistance

## Requirements

An internet connection is required.

## Usage

1. Install My AI Coder.
2. Open a project in VS Code.
3. Press `Ctrl + Shift + P`.
4. Search for `My AI Coder: Ask`.
5. Enter your question.

## Privacy

My AI Coder sends user prompts and relevant code to the AI service
to generate responses.
