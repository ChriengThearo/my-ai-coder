# My AI Coder

AI coding assistant for Visual Studio Code.

## Features

- Ask AI questions
- Explain code
- Analyze programming problems
- Get coding assistance

## Requirements

An internet connection is required. By default, My AI Coder uses the deployed
Axum backend at:

`https://beneficial-endurance-production-0d5d.up.railway.app`

You can override the backend in VS Code settings with `myAiCoder.apiBaseUrl`.
For local Axum development, set it to `http://127.0.0.1:8000`.

## Usage

1. Install My AI Coder.
2. Open a project in VS Code.
3. Open the My AI Coder activity bar view.
4. Enter your question in the chat input.

## Privacy

My AI Coder sends user prompts and relevant code to the AI service
to generate responses.
